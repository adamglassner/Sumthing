# Changelog

## 1.0.0 (2026-11-09)

First release of Sumthing, a calculator for Windows 10 and 11 by Bytehawk Studio.

- Standard calculator with memory (MC, MR, MS, M+, M−), history, percent, square, square root and 1/x. Works in exact decimals, so 0.1 + 0.2 is 0.3.
- Three looks: modern Light, modern Dark (or follow Windows), and Classic, which looks like the Windows 7 calculator with its View, Edit and Help menus. Seven accent colours for the modern looks.
- Tape: a paper roll beside the calculator that prints every step like an adding machine. Add a note to any line, then copy, save or print it.
- Type-a-sum: type whole sums, one per line, and see the answers as you type. Understands "12% of 340", "80 + 15%", "20% off 80", names such as "rent = 1,250", running totals and functions such as sqrt and round.
- Converter: length, weight, temperature, volume, area, speed, time, data and fuel economy, plus currencies with daily European Central Bank rates (kept for offline use).
- Everyday tools: tip and bill splitter, percent change, discount and sales tax, and date difference (with weekdays and add or take away days).
- Keyboard shortcuts for everything, keep on top, and history, memory and the tape kept between sessions.
- Installer (with a "just for me" option) and a portable zip. Available in the Bytehawk Studio Launcher.
